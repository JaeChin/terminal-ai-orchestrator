# Architect

Activate the Architecture Agent for system design.

## Usage
Provide a blueprint from the Plan Agent or describe what needs to be designed.

The agent will:
1. Review requirements and constraints
2. Design system architecture
3. Select technology stack with rationale
4. Define folder structure and data models
5. Document security architecture

## When to Use
- Have requirements, need technical design
- Choosing technologies
- Designing project structure
- Planning data models and APIs

## Output
Architecture document saved to `docs/plans/[project-name]-architecture.md`

## Next Step
After architecture is complete:
- Backend/infra work: `/devsecops`
- Frontend work: `/ui`
