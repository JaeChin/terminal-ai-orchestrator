# Block Task

Mark the current task as blocked and document why.

## Instructions

1. **Identify** the current "In Progress" task
2. **Ask** user for the blocker reason
3. **Add comment** to the Notion task:
```
   🚫 Blocked
   
   Reason: [why it's blocked]
   
   Unblock when: [what needs to happen]
   
   Related: [any dependent tasks]
```
4. **Update** Status to "Blocked"

## Output

- Confirmation that task is blocked
- Reminder of what's needed to unblock
- Offer to pull a different task
