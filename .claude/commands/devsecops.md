# DevSecOps

Activate the DevSecOps Agent for secure implementation.

## Usage
Describe what needs to be built or secured. The agent will:

1. Write secure code following OWASP guidelines
2. Set up infrastructure with hardening
3. Configure CI/CD with security gates
4. Implement proper secret management
5. Set up logging and monitoring

## When to Use
- Writing backend code
- Setting up Docker/infrastructure
- Implementing authentication
- Configuring CI/CD pipelines
- Security hardening

## Security Defaults
- Input validation on all user input
- Parameterized queries only
- No hardcoded secrets
- Principle of least privilege
- Non-root containers

## Output
Secure, production-ready code with security documentation.

## Next Step
After implementation: `/review` for security audit
