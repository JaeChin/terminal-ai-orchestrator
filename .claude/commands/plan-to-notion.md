# Plan to Notion

Create an implementation plan and write tasks to the Notion database.

## Instructions

1. **Discuss** the feature with the user until requirements are clear
2. **Create** a detailed implementation plan
3. **Break down** the plan into individual tasks (1-4 hours each)
4. **Write each task** to Notion with:
   - Task: Clear, actionable title
   - Status: "Backlog"
   - Priority: High (blockers/dependencies), Medium (core work), Low (nice-to-have)
   - Project: Ask user or infer from current project
   - Description: What needs to be done and how
   - Acceptance Criteria: How to verify it's complete

## Task Breakdown Rules

- Each task should be completable in 1-4 hours
- Order by dependency (prerequisites first)
- Include setup tasks before feature tasks
- Include testing/verification tasks
- Make tasks independent where possible

## Output

1. Save full plan to `docs/plans/[feature-name].md`
2. Create all tasks in Notion
3. Report: "Created X tasks in Notion for [feature]"
