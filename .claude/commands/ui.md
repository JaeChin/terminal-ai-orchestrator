# UI

Activate the UI Agent for frontend implementation.

## Usage
Describe the component or styling needed. The agent will:

1. Assess project context (React, static, Tailwind, etc.)
2. Apply consistent, maintainable styles
3. Ensure accessibility (WCAG 2.1 AA)
4. Optimize for performance
5. Build responsive layouts

## When to Use
- Building frontend components
- Styling or CSS work
- Accessibility improvements
- Responsive design issues
- Design system implementation

## Accessibility Defaults
- Semantic HTML
- Keyboard navigation
- Visible focus states
- Color contrast (4.5:1)
- ARIA labels where needed

## Output
Accessible, performant UI components with proper styling.
